# Proyecto de login

Aplicación web de inicio de sesión creada con Angular. Presenta una página de acceso sencilla y, después de iniciar sesión, un dashboard con el perfil del usuario.

## Funcionalidades

- Inicio de sesión con Google o GitHub.
- Dashboard personalizado con nombre, correo y foto de perfil.
- Diseño adaptable a pantallas de escritorio y dispositivos móviles.
- Cierre de sesión.

## Experiencia de la página

La página de inicio permite elegir un proveedor de acceso. Al completar el inicio de sesión, se muestra el dashboard con la información disponible del perfil y una opción para cerrar sesión.
